# Fonts

`shippori-500.woff2` and `shippori-800.woff2` are subsets of **Shippori Mincho B1** (FONTDASU), SIL Open Font License 1.1, downloaded from Google Fonts with a `text=` subset. They cover hiragana, katakana, digits, the 55 Tōkaidō station names and a few UI kanji (良 始 済 言 語). To add characters, request the subset again with the new text.
